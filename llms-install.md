# Установка drift для агента

Одна строка — сервер поднимается, ключи и регистрация не нужны.

```bash
claude mcp add --transport http drift https://drift.rta.lat/mcp
```

Или блок в конфиг MCP-клиента:

```json
{
  "mcpServers": {
    "drift": { "url": "https://drift.rta.lat/mcp" }
  }
}
```

Проверка, что всё живо:

```bash
curl -s https://drift.rta.lat/health
```

Инструменты:

| Инструмент | Что делает |
|---|---|
| `drift_check` | Проверить ОДНО предлагаемое действие по подписанному мандату. Возвращает `ALLOW` или `DENY` и правило, которое сработало. |
| `drift_session` | Проверить последовательность действий: сколько пропущено, сколько отклонено, каким правилом. |
| `drift_explain` | Шесть правил enforcement в том порядке, в каком они применяются, и зачем каждое существует. |

Шесть правил: сумма, получатель, аудитория, валюта, окно действия,
намерение (allowlist). Отказ по умолчанию: если правило не разрешает —
действие не проходит. Регистр отпечатка защищён от подмены.

Оплата: 100 проверок в сутки бесплатно, дальше $0.005 за вызов (x402, USDC
в сети Base) или подписка.
