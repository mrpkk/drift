## Заметки / рецепты

- **Суммы в минорных единицах, всегда.** `10000`, не `100.00`. Float в деньгах округляется в пользу плательщика.
- **Правило `amount` идёт первым.** Превышение лимита — самая частая форма дрейфа; иначе отказ назовёт второстепенную причину.
- **Не использовать `git add -A` в этом репозитории.** Трижды так в индекс попали `*.egg-info`, черновики PR и артефакты сборки. Перед коммитом смотреть `git status` глазами.
- **Русский в коде и конфигах — нельзя.** Трижды ловил `spellcheck` на русском комментарии. Все файлы проекта — английский.
- **Парсер укусил дважды.** Первая «деградация LLM» оказалась моей ошибкой разбора, а не поведением модели. Прежде чем делать вывод из замера — проверить на сыром выводе.
- **Cloudflared quick tunnel из РФ не маршрутизируется.** QUIC/7844 режет DPI (сам cloudflared советует `http2`), после переключения коннектор регистрируется на edge ams21, origin отвечает 200 — но edge отдаёт 404 на всех путях. Проверено: не propagation (5 попыток), не IPv6 (`curl -4`, A-запись 104.16.230.132). Нужен именованный tunnel с NS-делегацией.
- **GitHub Pages поднимается через POST, не PUT.** `PUT /pages` на несозданном сайте даёт 404; создание — `POST /repos/{owner}/{repo}/pages`. Сборку смотреть через `pages/builds/latest`, а sitemap отдаёт **предыдущую** сборку — поэтому сразу после пуша проверять статус, а не sitemap.
- **Jekyll-пермалинк надо задавать явно** во фронт-маттере каждого поста: дефолт `/YYYY/MM/DD/title.html` не совпадает со slug, который объявлен в статье.
- **Bare-функция после `unittest.main()` не выполняется.** Тест должен быть методом `TestCase` и стоять до точки входа — иначе счётчик молча остаётся прежним.
- **Путь с пробелами в bash:** `V=/путь/с пробелами` без кавычек разваливается — присваиваемое значение обрежется по первому пробелу, остальное станет командой. Всегда `V="…"` или путь без пробелов.
- **`pkill -f "строка"` может убить собственный шелл.** Шаблон совпадает с командной строкой самого баша — команда зависает. Брать PID из `systemctl show -p MainPID`.
- **Формат AP2 брать из эталонного SDK, а не из памяти.** Три места, где я ошибся: раскрытие (один base64-массив, не три сегмента), подпись (`header.payload` без подписи), `sd_jwt` (с завершающим `~`).

- **Сначала измерение, потом оптимизация.** Проверка `expected_aud` заняла один вечер и дала находку, которую не дало чтение кода за месяц.
